# 動画再生問題 診断手順

## 🔍 問題の特定手順

LINEアプリでCloudFront経由の動画が再生されない問題を診断するための手順です。

## ステップ1: 動画URLの確認

### 1-1. 動画URLの形式を確認

ログから動画URLを確認：
```
https://d33hx1uob3y8.cloudfront.net/videos/common/1767110912427_20251230_2312_01kdps1skefhbtnbxzdzx2ggjm.mp4
```

**確認項目**:
- [ ] URLがHTTPSで始まっているか
- [ ] CloudFrontドメインが正しいか
- [ ] パスが正しいか（`/videos/common/...`）

### 1-2. ブラウザで直接アクセス

PCのブラウザで動画URLに直接アクセスして、動画が再生できるか確認：

```
https://d33hx1uob3y8.cloudfront.net/videos/common/1767110912427_20251230_2312_01kdps1skefhbtnbxzdzx2ggjm.mp4
```

**期待される結果**:
- ✅ 動画が再生される → CloudFrontの設定は正常
- ❌ 403 Forbidden → S3バケットポリシーの問題
- ❌ 404 Not Found → ファイルが存在しない、またはパスが間違っている
- ❌ その他のエラー → CloudFrontの設定に問題がある可能性

## ステップ2: レスポンスヘッダーの確認

### 2-1. ブラウザの開発者ツールで確認

1. PCのブラウザで動画URLにアクセス
2. 開発者ツール（F12）を開く
3. **Network**タブを開く
4. 動画ファイルのリクエストを選択
5. **Headers**タブでレスポンスヘッダーを確認

**確認すべきヘッダー**:

| ヘッダー名 | 期待される値 | 説明 |
|-----------|------------|------|
| `Access-Control-Allow-Origin` | `*` または `line://` | CORS設定 |
| `Access-Control-Allow-Methods` | `GET, HEAD, OPTIONS` | 許可されたHTTPメソッド |
| `Access-Control-Expose-Headers` | `Content-Length, Content-Type, ...` | 公開されるヘッダー |
| `Content-Type` | `video/mp4` | 動画のMIMEタイプ |
| `Accept-Ranges` | `bytes` | Rangeリクエストのサポート |
| `Content-Length` | ファイルサイズ（バイト） | ファイルサイズ |

**問題の可能性**:
- `Access-Control-Allow-Origin`が存在しない → CORS設定が不足
- `Content-Type`が`video/mp4`でない → S3オブジェクトのメタデータが不正
- `Accept-Ranges`が存在しない → ストリーミング再生ができない可能性

### 2-2. curlコマンドで確認

ターミナルで以下のコマンドを実行：

```bash
curl -I "https://d33hx1uob3y8.cloudfront.net/videos/common/1767110912427_20251230_2312_01kdps1skefhbtnbxzdzx2ggjm.mp4"
```

**確認項目**:
- ステータスコードが`200 OK`であること
- `Access-Control-Allow-Origin`ヘッダーが存在すること
- `Content-Type`が`video/mp4`であること

### 2-3. OPTIONSリクエスト（Preflight）の確認

CORSのPreflightリクエストが正しく処理されているか確認：

```bash
curl -X OPTIONS \
  -H "Origin: line://" \
  -H "Access-Control-Request-Method: GET" \
  -H "Access-Control-Request-Headers: Content-Type" \
  -v "https://d33hx1uob3y8.cloudfront.net/videos/common/1767110912427_20251230_2312_01kdps1skefhbtnbxzdzx2ggjm.mp4"
```

**期待されるレスポンス**:
- ステータスコード: `200 OK` または `204 No Content`
- `Access-Control-Allow-Origin: line://` または `*`
- `Access-Control-Allow-Methods: GET, HEAD, OPTIONS`
- `Access-Control-Allow-Headers: *` または 具体的なヘッダー名

## ステップ3: S3バケットの設定確認

### 3-1. CORS設定の確認

1. [AWS S3コンソール](https://s3.console.aws.amazon.com/)にアクセス
2. 対象のバケット（`gacha-lab-test`）を選択
3. 「アクセス許可」タブを開く
4. 「クロスオリジンリソース共有（CORS）」セクションを確認

**確認項目**:
- [ ] CORS設定が存在する
- [ ] `AllowedOrigins`に`line://`が含まれている
- [ ] `AllowedOrigins`に`https://liff.line.me`が含まれている
- [ ] `AllowedMethods`に`GET`、`HEAD`、`OPTIONS`が含まれている
- [ ] `ExposeHeaders`に`Content-Range`と`Accept-Ranges`が含まれている

### 3-2. バケットポリシーの確認

1. S3コンソールで、対象のバケットを選択
2. 「アクセス許可」タブを開く
3. 「バケットポリシー」セクションを確認

**確認項目**:
- [ ] CloudFrontからのアクセスが許可されている
- [ ] Origin Access Control（OAC）が正しく設定されている

### 3-3. オブジェクトのメタデータ確認

1. S3コンソールで、動画ファイルを選択
2. 「プロパティ」タブを開く
3. 「メタデータ」セクションを確認

**確認項目**:
- [ ] `Content-Type`が`video/mp4`に設定されている
- [ ] `Cache-Control`が適切に設定されている（オプション）

## ステップ4: CloudFrontの設定確認

### 4-1. ディストリビューションの状態確認

1. [AWS CloudFrontコンソール](https://console.aws.amazon.com/cloudfront/)にアクセス
2. 対象のディストリビューション（`d33hx1uob3y8`）を選択
3. 「一般」タブでステータスを確認

**確認項目**:
- [ ] ステータスが「Deployed」であること
- [ ] ドメイン名が正しいこと

### 4-2. ビヘイビアの設定確認

1. CloudFrontコンソールで、対象のディストリビューションを選択
2. 「ビヘイビア」タブを開く
3. デフォルトのビヘイビア（`*`）を選択して「編集」をクリック

**確認項目**:
- [ ] **レスポンスヘッダーポリシー**: CORS設定が含まれている
- [ ] **キャッシュキーとオリジンリクエスト**: Rangeリクエストがサポートされている
- [ ] **許可されたHTTPメソッド**: `GET`、`HEAD`、`OPTIONS`が含まれている

### 4-3. オリジンの設定確認

1. CloudFrontコンソールで、対象のディストリビューションを選択
2. 「オリジン」タブを開く
3. S3オリジンを選択

**確認項目**:
- [ ] オリジンドメインが正しいS3バケットを指している
- [ ] Origin Access Control（OAC）が設定されている

## ステップ5: LINEアプリ側の確認

### 5-1. LIFFアプリの設定確認

1. [LINE Developersコンソール](https://developers.line.biz/)にアクセス
2. 対象のLIFFアプリを選択
3. 「設定」タブを開く

**確認項目**:
- [ ] **エンドポイントURL**: 正しいURLが設定されている
- [ ] **Content Security Policy**: CloudFrontドメインが許可されている（オプション）

### 5-2. ブラウザの開発者ツールで確認（LINEアプリ内）

LINEアプリ内のブラウザで開発者ツールを開き、以下を確認：

1. **Networkタブ**: 動画ファイルへのリクエストを確認
   - ステータスコード
   - レスポンスヘッダー
   - エラーメッセージ

2. **Consoleタブ**: エラーメッセージを確認
   - CORSエラー
   - 動画の読み込みエラー
   - その他のエラー

## ステップ6: 動画ファイルの確認

### 6-1. 動画ファイルの形式確認

動画ファイルがLINEアプリでサポートされている形式か確認：

**推奨形式**:
- **コンテナ**: MP4
- **ビデオコーデック**: H.264
- **オーディオコーデック**: AAC
- **解像度**: 1080p以下
- **ビットレート**: 5Mbps以下

### 6-2. 動画ファイルのサイズ確認

動画ファイルが大きすぎる場合、読み込みに時間がかかる可能性があります。

**確認項目**:
- [ ] ファイルサイズが適切か（100MB以下を推奨）
- [ ] 動画の長さが適切か（30秒以下を推奨）

## 📊 診断結果のまとめ

以下のチェックリストに基づいて、問題を特定してください：

| 項目 | 状態 | 問題の可能性 |
|-----|------|------------|
| ブラウザで直接アクセスできる | ✅/❌ | CloudFront/S3の基本設定 |
| CORSヘッダーが存在する | ✅/❌ | CORS設定 |
| Content-Typeが正しい | ✅/❌ | S3オブジェクトのメタデータ |
| OPTIONSリクエストが成功する | ✅/❌ | CORS設定 |
| S3バケットのCORS設定 | ✅/❌ | S3のCORS設定 |
| CloudFrontのレスポンスヘッダーポリシー | ✅/❌ | CloudFrontのCORS設定 |
| 動画ファイルの形式 | ✅/❌ | 動画ファイルの問題 |

## 🔧 よくある問題と解決策

### 問題1: CORSエラーが発生する

**症状**: ブラウザのコンソールに`Access-Control-Allow-Origin`エラーが表示される

**解決策**:
1. S3バケットのCORS設定に`line://`を追加
2. CloudFrontのレスポンスヘッダーポリシーでCORSを設定
3. CloudFrontのキャッシュを無効化

### 問題2: 動画が読み込まれない

**症状**: 動画が表示されない、またはエラーが発生する

**解決策**:
1. S3オブジェクトのContent-Typeを確認
2. 動画ファイルの形式を確認
3. CloudFrontのキャッシュを無効化

### 問題3: 動画が途中で止まる

**症状**: 動画が途中で再生が止まる

**解決策**:
1. Rangeリクエストがサポートされているか確認
2. CloudFrontのキャッシュポリシーを確認
3. 動画ファイルのサイズを確認
