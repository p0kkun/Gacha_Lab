# S3バケットポリシー修正手順

## 🔍 確認結果の分析

### ✅ 正しく設定されている項目

1. **CloudFront設定**: 
   - ディストリビューションID: `E2O1UP219WO08E`
   - オリジン: `gacha-lab-test.s3.ap-northeast-1.amazonaws.com`
   - ビヘイビア: デフォルト（*）が設定されている

2. **IAMユーザー**:
   - ユーザー名: `gacha-lab-s3-uploader`
   - アクセスキーID: `AKIAxxxxxxxxxxxxxxxx`（アクティブ）
   - ポリシー: `GachaLabS3UploadPolicy` がアタッチされている

3. **S3バケットポリシー（CloudFront用）**:
   - CloudFrontサービスプリンシパルが`GetObject`権限を持っている ✅

### ❌ 問題点

**S3バケットポリシーにIAMユーザーのアクセス許可が含まれていません。**

現在のバケットポリシーには、CloudFrontからの読み取り（`GetObject`）のみが許可されていますが、IAMユーザー（`gacha-lab-s3-uploader`）がS3にアップロード（`PutObject`）できるようにするための許可がありません。

## 🔧 修正手順

### ステップ 1: S3バケットポリシーを編集

1. [AWS マネジメントコンソール](https://console.aws.amazon.com/)にアクセス
2. 「S3」サービスを選択
3. `gacha-lab-test` バケットをクリック
4. 「アクセス許可」タブをクリック
5. 「バケットポリシー」セクションで「編集」をクリック

### ステップ 2: ポリシーを更新

現在のポリシーに、IAMユーザーのアクセス許可を追加します。

**現在のポリシー**:
```json
{
    "Version": "2008-10-17",
    "Id": "PolicyForCloudFrontPrivateContent",
    "Statement": [
        {
            "Sid": "AllowCloudFrontServicePrincipal",
            "Effect": "Allow",
            "Principal": {
                "Service": "cloudfront.amazonaws.com"
            },
            "Action": "s3:GetObject",
            "Resource": "arn:aws:s3:::gacha-lab-test/*",
            "Condition": {
                "ArnLike": {
                    "AWS:SourceArn": "arn:aws:cloudfront::957053480412:distribution/E2O1UP219WO08E"
                }
            }
        }
    ]
}
```

**修正後のポリシー**（以下のJSONをコピー＆ペースト）:
```json
{
    "Version": "2008-10-17",
    "Id": "PolicyForCloudFrontPrivateContent",
    "Statement": [
        {

            "Effect": "Allow",

            },
            "Action": [
                "s3:PutObject",

                "s3:ListBucket"

                "arn:aws:s3:::gacha-lab-test",
```

## ✅ 確認ポイント

修正後のポリシーで以下が許可されます：

1. **CloudFrontサービスプリンシパル**:
   - `s3:GetObject` - CloudFrontがS3からファイルを読み取る

2. **IAMユーザー（gacha-lab-s3-uploader）**:
   - `s3:PutObject` - ファイルをアップロード
   - `s3:GetObject` - ファイルを読み取る
   - `s3:DeleteObject` - ファイルを削除
   - `s3:ListBucket` - バケット内のファイル一覧を取得

## 🔍 IAMポリシーの確認（念のため）

IAMユーザーにアタッチされているポリシー（`GachaLabS3UploadPolicy`）の詳細も確認してください。

### 確認手順

1. IAMコンソール → 「ポリシー」を選択
2. `GachaLabS3UploadPolicy` を検索してクリック
3. 「JSON」タブをクリック
4. 以下のような内容になっていることを確認：

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:PutObject",
        "s3:GetObject",
        "s3:DeleteObject",
        "s3:ListBucket"
      ],
      "Resource": [
        "arn:aws:s3:::gacha-lab-test",
        "arn:aws:s3:::gacha-lab-test/*"
      ]
    }
  ]
}
```

**注意**: IAMポリシーとS3バケットポリシーの両方で同じ権限を設定する必要があります。これは「最小権限の原則」に従った設定です。

## ⚠️ よくあるエラーと対処法

### エラー: `Access Denied` または `403 Forbidden`

- **原因**: バケットポリシーが正しく更新されていない、またはIAMポリシーに問題がある
- **対処**: 
  1. バケットポリシーが正しく保存されているか確認
  2. IAMポリシーのJSONを確認
  3. アカウントID（`957053480412`）とユーザー名（`gacha-lab-s3-uploader`）が正しいか確認

### エラー: `InvalidAccessKeyId`

- **原因**: アクセスキーIDが間違っている、または無効
- **対処**: 環境変数`S3_ACCESS_KEY_ID`が`AKIAxxxxxxxxxxxxxxxx`に設定されているか確認

### エラー: `SignatureDoesNotMatch`

- **原因**: シークレットアクセスキーが間違っている
- **対処**: 環境変数`S3_SECRET_ACCESS_KEY`が正しく設定されているか確認
