# ローカル環境での S3 アップロード設定

ローカル開発環境から実際の AWS S3 にアップロードする方法を説明します。

## 📋 概要

ローカル環境から S3 にアップロードする方法は 2 つあります：

1. **実際の AWS S3 を使用**（推奨）: 本番環境と同じ設定でテストできる
2. **LocalStack を使用**: ローカルで S3 をエミュレート（AWS コストがかからない）

このドキュメントでは、**実際の AWS S3 を使用する方法**を説明します。

---

## ✅ 前提条件

- AWS アカウントを持っていること
- IAM ユーザーのアクセスキー ID とシークレットアクセスキーを持っていること
- S3 バケットが作成されていること

---

## 🔧 設定手順

### ステップ 1: `.env.local`ファイルを確認・作成

プロジェクトのルートディレクトリ（`Gacha_Lab/app/`）に`.env.local`ファイルがあるか確認します。

### ステップ 2: 環境変数を設定

`.env.local`ファイルに以下の環境変数を追加または更新します：

```env
# S3設定（実際のAWS S3を使用）
S3_REGION=ap-northeast-1
S3_ACCESS_KEY_ID=AKIAxxxxxxxxxxxxxxxx
S3_SECRET_ACCESS_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
S3_BUCKET_NAME=gacha-lab-test
CLOUDFRONT_DOMAIN=d33hx1uob3y8zt.cloudfront.net

# LocalStackを使用しない（実際のAWS S3を使用）
USE_LOCALSTACK=false
```

### ステップ 3: 環境変数の説明

| 環境変数名             | 値                                         | 説明                                            |
| ---------------------- | ------------------------------------------ | ----------------------------------------------- |
| `S3_REGION`            | `ap-northeast-1`                           | S3 バケットのリージョン                         |
| `S3_ACCESS_KEY_ID`     | `AKIAxxxxxxxxxxxxxxxx`                     | IAM ユーザーのアクセスキー ID                   |
| `S3_SECRET_ACCESS_KEY` | `xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` | IAM ユーザーのシークレットアクセスキー          |
| `S3_BUCKET_NAME`       | `gacha-lab-test`                           | S3 バケット名                                   |
| `CLOUDFRONT_DOMAIN`    | `d33hx1uob3y8zt.cloudfront.net`            | CloudFront ディストリビューションのドメイン     |
| `USE_LOCALSTACK`       | `false`                                    | LocalStack を使用しない（実際の AWS S3 を使用） |

**重要**:

- `USE_LOCALSTACK=false` に設定することで、実際の AWS S3 にアップロードされます
- `USE_LOCALSTACK=true` に設定すると、LocalStack（ローカル S3 エミュレーター）を使用します

## 🧪 動作確認

### 1. 開発サーバーを起動

```bash
npm run dev
```

### 2. 管理画面にアクセス

- URL: `http://localhost:3000/admin`
- ログイン

### 3. 動画管理ページを開く

- 左メニューから「動画管理」をクリック

### 4. 動画をアップロード

- 「動画をアップロード」ボタンをクリック
- 動画ファイルを選択（MP4 形式、100MB 以下）
- 動画タイプを選択（COMMON または RARITY）
- アップロードを実行

### 5. エラーの確認

- ブラウザの開発者ツール（F12）を開く
- 「Console」タブでエラーを確認
- 「Network」タブで API リクエストのステータスを確認
- ステータスコードが`200`であることを確認

### 6. S3 バケットの確認

- AWS コンソール → S3 → `gacha-lab-test` バケットを開く
- `videos/`フォルダにアップロードされたファイルが表示されることを確認

## 🔄 LocalStack と実際の AWS S3 の切り替え

### 実際の AWS S3 を使用する場合

```env
USE_LOCALSTACK=false
S3_REGION=ap-northeast-1
S3_ACCESS_KEY_ID=AKIAxxxxxxxxxxxxxxxx
S3_SECRET_ACCESS_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
S3_BUCKET_NAME=gacha-lab-test
CLOUDFRONT_DOMAIN=d33hx1uob3y8zt.cloudfront.net
```

### LocalStack を使用する場合

```env
USE_LOCALSTACK=true
LOCALSTACK_ENDPOINT=http://127.0.0.1:4566
LOCALSTACK_BASE_URL=http://127.0.0.1:4566
S3_BUCKET_NAME=gacha-lab-test
# アクセスキーは任意の値でOK
S3_ACCESS_KEY_ID=test
S3_SECRET_ACCESS_KEY=test
```

**注意**: LocalStack を使用する場合は、事前に LocalStack を起動する必要があります：

```bash
npm run localstack:up
npm run localstack:setup
```

## ⚠️ よくあるエラーと対処法

### エラー: `Access Denied` または `403 Forbidden`

- **原因**: S3 バケットポリシーに IAM ユーザーのアクセス許可が含まれていない
- **対処**: [S3 バケットポリシー修正手順](./S3バケットポリシー修正手順.md)を参照

### エラー: `The bucket you are attempting to access must be addressed using the specified endpoint`

- **原因**: リージョン設定の不一致
- **対処**: `S3_REGION`環境変数が`ap-northeast-1`に設定されているか確認

### エラー: `InvalidAccessKeyId`

- **原因**: アクセスキー ID が間違っている、または無効
- **対処**: `S3_ACCESS_KEY_ID`環境変数が正しく設定されているか確認

### エラー: `SignatureDoesNotMatch`

- **原因**: シークレットアクセスキーが間違っている
- **対処**: `S3_SECRET_ACCESS_KEY`環境変数が正しく設定されているか確認

### エラー: `ECONNREFUSED`（LocalStack 使用時）

- **原因**: LocalStack が起動していない
- **対処**: `npm run localstack:up`を実行して LocalStack を起動

## 💡 補足情報

### セキュリティに関する注意

- `.env.local`ファイルは`.gitignore`に含まれているため、Git にコミットされません
- アクセスキー ID とシークレットアクセスキーは機密情報です。絶対に公開しないでください
- 本番環境では、AWS Amplify の環境変数設定を使用してください

### コストに関する注意

- 実際の AWS S3 を使用する場合、ストレージと転送にコストがかかります
- 開発・テスト目的の場合は、LocalStack を使用することでコストを削減できます
- ただし、LocalStack では CloudFront の動作確認はできません
