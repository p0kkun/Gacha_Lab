### Q2: ガチャの動画と画像は違うバケットのほうがいいのか？

**A: 同じバケットでディレクトリを分ける方が推奨です。**

#### 比較表

| 項目 | 同じバケット（ディレクトリ分け） | 別バケット |
|------|--------------------------------|-----------|
| **管理の簡単さ** | ✅ 1つのバケットで管理 | ❌ 複数バケットを管理 |
| **CloudFront設定** | ✅ 1つのディストリビューション | ❌ 複数のディストリビューション |
| **コスト** | ✅ 同じ（ストレージ料金は同じ） | ✅ 同じ（ストレージ料金は同じ） |
| **IAMポリシー** | ✅ 1つのポリシーで管理 | ❌ 複数のポリシーが必要 |
| **アクセス制御** | ✅ 統一的な制御 | ⚠️ バケットごとに設定 |
| **ディレクトリ構造** | ✅ `videos/` と `images/` で分離 | ✅ 完全に分離 |
| **拡張性** | ✅ 将来的に追加ディレクトリも可能 | ⚠️ バケット追加が必要 |

#### 推奨: 同じバケット + ディレクトリ分け

**理由**:
1. **管理が簡単**: 1つのバケットで動画・画像を一元管理
2. **CloudFront設定が簡単**: 1つのディストリビューションで両方に対応
3. **コスト効率**: ストレージ料金は同じ（バケット数は関係ない）
4. **柔軟性**: 将来的に他のファイルタイプも追加しやすい

**別バケットが適している場合**:
- 動画と画像で**完全に異なるアクセス権限**が必要な場合
- 動画と画像で**異なるCloudFrontキャッシュポリシー**が必要な場合
- **組織的に完全に分離**したい場合

### Q3: バケット内でディレクトリを分けてアップも可能か？

**A: はい、可能です。既に実装済みです。**

現在の実装では、以下のようにディレクトリを分けて保存しています：

```
バケット名（例: gacha-lab-test）/
├── videos/              # 動画ファイル
│   ├── common/          # 共通動画
│   │   └── [タイムスタンプ]_[ファイル名].mp4
│   └── rarity/          # 等級別動画
│       ├── first-prize/
│       ├── second-prize/
│       ├── third-prize/
│       ├── fourth-prize/
│       └── fifth-prize/
└── images/              # 画像ファイル
    ├── gacha-types/     # ガチャタイプのアイコン画像
    │   └── [ガチャタイプID]/
    │       └── [タイムスタンプ]_[ファイル名].png
    ├── common/          # 将来的に使用
    └── rarity/          # 将来的に使用
```

**S3のディレクトリ構造について**:
- S3には実際の「ディレクトリ」は存在しませんが、**キー（パス）で論理的に分離**できます
- `videos/common/` と `images/gacha-types/` は異なるキーとして扱われます
- AWSコンソールでは「フォルダ」として表示されます

## 💡 推奨構成

### 推奨: 同じバケット + ディレクトリ分け（現在の実装）

```
バケット名: gacha-lab-test（または gacha-lab-20241228）
├── videos/              # 動画
│   ├── common/
│   └── rarity/
└── images/              # 画像
    ├── gacha-types/
    ├── common/
    └── rarity/
```

**メリット**:
- ✅ 1つのバケットで一元管理
- ✅ CloudFront設定が1つで済む
- ✅ IAMポリシーがシンプル
- ✅ コスト効率が良い
- ✅ 将来的な拡張が容易

## 🔧 実装状況

現在の実装では、以下のようにディレクトリ分けが実装されています：

1. **動画アップロード**: `videos/common/` または `videos/rarity/[等級]/`
2. **ガチャタイプアイコン**: `images/gacha-types/[ガチャタイプID]/`
3. **将来的な画像**: `images/common/` または `images/rarity/[等級]/`

すべて同じバケット内で、キー（パス）で分離されています。
