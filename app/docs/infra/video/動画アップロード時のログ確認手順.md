# 動画アップロード時のログ確認手順

CloudWatchで動画アップロード関連のログが表示されない場合の確認手順です。

## 🔍 問題の状況

- CloudWatchに通常のリクエストログ（START、REPORT）は表示されている
- しかし、`S3アップロード設定:`や`S3アップロードエラー詳細:`などのログが表示されない

## 🎯 考えられる原因

1. **動画アップロードAPIが呼び出されていない**
   - フロントエンドでエラーが発生してAPIリクエストが送信されていない
   - 認証エラーでAPIに到達していない

2. **ログのタイムスタンプが異なる**
   - 古いログを見ている
   - 最新のログストリームを見ていない

3. **ログが別のログストリームに出力されている**
   - 複数のログストリームが存在する

## 🔧 確認手順

### ステップ1: 動画アップロードを実行

1. DEV環境の管理画面にアクセス
2. ブラウザの開発者ツール（F12）を開く
3. 「Network」タブを開く
4. 「動画管理」ページを開く
5. 動画をアップロード
6. Networkタブで `/api/admin/videos/upload` リクエストを確認

### ステップ2: リクエストの確認

Networkタブで以下を確認：

- **リクエストが送信されているか**
  - `/api/admin/videos/upload` が表示されているか
  - ステータスコードは何か（200、400、500など）

- **リクエストのタイムスタンプ**
  - リクエストが送信された時刻をメモ

### ステップ3: CloudWatchでログを確認

1. CloudWatchコンソールにアクセス
2. ロググループ `/aws/amplify/d2zlbom9902v0u` を開く
3. **最新のログストリーム**を選択（複数ある場合は最新のものを選択）
4. **動画アップロードを実行した時刻**のログを確認
5. 以下のキーワードで検索：
   - `S3アップロード`
   - `動画アップロード`
   - `videos/upload`
   - `エラー`

### ステップ4: ログストリームの確認

複数のログストリームがある場合：

1. ログストリーム一覧を確認
2. **最新のタイムスタンプ**のログストリームを選択
3. 各ログストリームで `S3アップロード` を検索

## 🧪 デバッグ方法

### 方法1: ブラウザのコンソールで確認

動画アップロード時に、ブラウザのコンソールにエラーが表示されていないか確認：

1. 開発者ツール（F12）を開く
2. 「Console」タブを開く
3. 動画をアップロード
4. エラーメッセージを確認

### 方法2: Networkタブでレスポンスを確認

1. 開発者ツール（F12）を開く
2. 「Network」タブを開く
3. 動画をアップロード
4. `/api/admin/videos/upload` リクエストをクリック
5. 「Response」タブでレスポンス内容を確認
6. 「Headers」タブでステータスコードを確認

### 方法3: 一時的なデバッグエンドポイントを作成

環境変数の設定状況を確認するための一時的なエンドポイント：

```typescript
// app/api/debug/s3-env/route.ts（一時的なデバッグ用）
import { NextResponse } from 'next/server';
import { verifyAdminAuth } from '@/lib/admin-auth';

export async function GET(request: Request) {
  // 認証チェック
  if (!verifyAdminAuth(request)) {
    return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
  }

  return NextResponse.json({
    S3_REGION: process.env.S3_REGION || process.env.AWS_REGION || '未設定',
    S3_ACCESS_KEY_ID: process.env.S3_ACCESS_KEY_ID || process.env.AWS_ACCESS_KEY_ID ? '***設定済み***' : '未設定',
    S3_SECRET_ACCESS_KEY: process.env.S3_SECRET_ACCESS_KEY || process.env.AWS_SECRET_ACCESS_KEY ? '***設定済み***' : '未設定',
    S3_BUCKET_NAME: process.env.S3_BUCKET_NAME || process.env.AWS_S3_BUCKET_NAME || '未設定',
    CLOUDFRONT_DOMAIN: process.env.CLOUDFRONT_DOMAIN || process.env.AWS_CLOUDFRONT_DOMAIN || '未設定',
    USE_LOCALSTACK: process.env.USE_LOCALSTACK || 'false',
  });
}
```

**使用方法**:
1. 上記のファイルを作成
2. DEV環境にデプロイ
3. ブラウザで `/api/debug/s3-env` にアクセス（管理画面にログインした状態で）
4. 環境変数の設定状況を確認
5. **確認後は必ずこのファイルを削除してください**

## 📊 ログが表示されない場合の対処法

### ケース1: リクエストが送信されていない

**症状**: Networkタブに `/api/admin/videos/upload` が表示されない

**原因**: 
- フロントエンドでエラーが発生
- 認証トークンが無効
- ファイル選択が失敗

**対処**:
- ブラウザのコンソールでエラーを確認
- 認証トークンが正しく設定されているか確認

### ケース2: リクエストは送信されているが、ログが表示されない

**症状**: Networkタブにリクエストは表示されるが、CloudWatchにログがない

**原因**:
- APIエンドポイントに到達していない
- エラーが発生してログ出力前に処理が止まっている

**対処**:
- Networkタブでレスポンスを確認
- ステータスコードを確認（500エラーの場合、サーバーサイドでエラーが発生）

### ケース3: ログのタイムスタンプが異なる

**症状**: ログは表示されるが、動画アップロード時のログではない

**対処**:
- 動画アップロードを実行した正確な時刻をメモ
- その時刻のログを確認
- 最新のログストリームを確認
