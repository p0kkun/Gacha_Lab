# DEV環境でのS3アップロードエラー対処法

ローカル環境では成功するが、DEV環境（AWS Amplify）で失敗する場合の対処法を説明します。

## 🔍 考えられる原因

1. **環境変数が正しく設定されていない**
2. **S3バケットポリシーが修正されていない**（IAMユーザーのアクセス許可が不足）
3. **ネットワークエラーやタイムアウト**
4. **AWS認証情報の問題**

---

## 📋 確認手順

### ステップ 1: 環境変数の確認

AWS Amplifyコンソールで以下の環境変数が設定されているか確認してください：

| 環境変数名 | 値 | 必須 |
|-----------|-----|------|
| `S3_REGION` | `ap-northeast-1` | ✅ |
| `S3_ACCESS_KEY_ID` | `AKIAxxxxxxxxxxxxxxxx` | ✅ |
| `S3_SECRET_ACCESS_KEY` | `xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` | ✅ |
| `S3_BUCKET_NAME` | `gacha-lab-test` | ✅ |
| `CLOUDFRONT_DOMAIN` | `d33hx1uob3y8zt.cloudfront.net` | ✅ |
| `USE_LOCALSTACK` | `false` または未設定 | ✅ |

**確認方法**:
1. AWS Amplifyコンソールにアクセス
2. アプリを選択
3. 「環境変数」をクリック
4. 上記の環境変数がすべて設定されているか確認

### ステップ 2: S3バケットポリシーの確認

S3バケットポリシーにIAMユーザーのアクセス許可が追加されているか確認してください。

**確認方法**:
1. AWSコンソール → S3 → `gacha-lab-test` バケット
2. 「アクセス許可」タブ → 「バケットポリシー」
3. 以下のステートメントが含まれているか確認：

```json
{
    "Sid": "AllowIAMUserAccess",
    "Effect": "Allow",
    "Principal": {
        "AWS": "arn:aws:iam::957053480412:user/gacha-lab-s3-uploader"
    },
    "Action": [
        "s3:PutObject",
        "s3:GetObject",
        "s3:DeleteObject",
        "s3:ListBucket"
    ],
    "Resource": [
        "arn:aws:s3:::gacha-lab-test",
        "arn:aws:s3:::gacha-lab-test/*"
    ]
}
```

**まだ追加していない場合**: [S3バケットポリシー修正手順](./S3バケットポリシー修正手順.md)を参照してください。

### ステップ 3: エラーログの確認

DEV環境でのエラーログを確認してください。

**確認方法**:
1. AWS Amplifyコンソール → アプリを選択
2. 「モニタリング」→ 「ログ」をクリック
3. 最新のログを確認
4. エラーメッセージを探す

**よくあるエラーメッセージ**:
- `Access Denied` → S3バケットポリシーの問題
- `InvalidAccessKeyId` → 環境変数の設定ミス
- `SignatureDoesNotMatch` → シークレットアクセスキーの設定ミス
- `The bucket you are attempting to access must be addressed using the specified endpoint` → リージョン設定の不一致

### ステップ 4: ブラウザの開発者ツールで確認

DEV環境の管理画面で動画アップロードを試し、ブラウザの開発者ツールでエラーを確認してください。

**確認方法**:
1. DEV環境の管理画面にアクセス
2. ブラウザの開発者ツール（F12）を開く
3. 「Console」タブでエラーを確認
4. 「Network」タブで `/api/admin/videos/upload` リクエストを確認
5. レスポンスの内容を確認

---

## 🔧 対処法

### 対処法 1: 環境変数の再設定

環境変数が正しく設定されていない場合：

1. AWS Amplifyコンソール → アプリ → 「環境変数」
2. 各環境変数を確認・修正
3. 「保存」をクリック
4. **アプリを再デプロイ**（重要）

**注意**: 環境変数を変更した後は、必ずアプリを再デプロイしてください。

### 対処法 2: S3バケットポリシーの修正

S3バケットポリシーにIAMユーザーのアクセス許可を追加してください。

詳細は [S3バケットポリシー修正手順](./S3バケットポリシー修正手順.md) を参照してください。

### 対処法 3: IAMユーザーの権限確認

IAMユーザー（`gacha-lab-s3-uploader`）に正しい権限が付与されているか確認してください。

1. IAMコンソール → ユーザー → `gacha-lab-s3-uploader`
2. 「アクセス権限」タブで `GachaLabS3UploadPolicy` がアタッチされているか確認
3. ポリシーの内容を確認

---

## 🧪 テスト手順

修正後、以下の手順でテストしてください：

1. **環境変数を確認・修正**
2. **S3バケットポリシーを修正**
3. **アプリを再デプロイ**
4. **DEV環境の管理画面にアクセス**
5. **動画をアップロード**
6. **エラーログを確認**
