# 環境変数チェックリスト

## 動画アップロード機能に必要な環境変数

### ✅ 必須環境変数（すべて設定済み）

| 環境変数名 | 設定値 | 説明 | 状態 |
|-----------|--------|------|------|
| `S3_REGION` | `ap-northeast-1` | S3バケットのリージョン | ✅ 設定済み |
| `S3_ACCESS_KEY_ID` | `AKIAxxxxxxxxxxxxxxxx` | AWSアクセスキーID | ✅ 設定済み |
| `S3_SECRET_ACCESS_KEY` | `xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` | AWSシークレットアクセスキー | ✅ 設定済み |
| `S3_BUCKET_NAME` | `gacha-lab-test` | S3バケット名 | ✅ 設定済み |
| `CLOUDFRONT_DOMAIN` | `d33hx1uob3y8zt.cloudfront.net` | CloudFrontディストリビューションのドメイン | ✅ 設定済み |

### 📝 補足情報

- **代替環境変数名**: コードでは後方互換性のため、以下の環境変数名もサポートされています：
  - `AWS_REGION` → `S3_REGION` の代替
  - `AWS_ACCESS_KEY_ID` → `S3_ACCESS_KEY_ID` の代替
  - `AWS_SECRET_ACCESS_KEY` → `S3_SECRET_ACCESS_KEY` の代替
  - `AWS_S3_BUCKET_NAME` → `S3_BUCKET_NAME` の代替
  - `AWS_CLOUDFRONT_DOMAIN` → `CLOUDFRONT_DOMAIN` の代替

- **LocalStack用環境変数（本番環境では不要）**:
  - `USE_LOCALSTACK` - ローカル開発環境でのみ使用（デフォルト: `false`）
  - `LOCALSTACK_ENDPOINT` - ローカル開発環境でのみ使用
  - `LOCALSTACK_BASE_URL` - ローカル開発環境でのみ使用

## ✅ 確認結果

**すべての必須環境変数が正しく設定されています。**

動画アップロード機能は正常に動作するはずです。

## 🔍 動作確認方法

1. 管理画面にアクセス
2. 「動画管理」メニューを開く
3. 動画をアップロードしてみる
4. ブラウザのコンソールでエラーがないか確認
5. S3バケットにファイルがアップロードされているか確認

## ⚠️ 注意事項

- CloudFrontを使用している場合、アップロードされたファイルは即座にCloudFront経由でアクセス可能になります
- S3バケットのポリシーとCloudFrontの設定が正しく行われていることを確認してください
- 本番環境では、`gacha-lab-test`ではなく`gacha-lab-prod`などの本番用バケット名を使用することを推奨します
