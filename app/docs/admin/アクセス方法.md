# 管理画面アクセス方法

## 概要

Gacha Lab の管理画面へのアクセス方法と認証情報を説明します。

---

## 🔗 アクセス URL

### ローカル開発環境

```
http://localhost:3000/admin
```

### 本番環境（AWS Amplify）

```
https://your-domain.amplifyapp.com/admin
```

または

```
https://main.xxxxxxxxxxxx.amplifyapp.com/admin
```

---

## 📱 LINE 公式アカウントから管理画面 URL を取得

**管理画面の URL を覚えられない場合、LINE 公式アカウントに特定のキーワードを送信すると、管理画面への URL を返信します。**

### 使用方法

1. **LINE 公式アカウントを友だち追加**

   - Gacha Lab の LINE 公式アカウントを友だち追加

2. **管理者用キーワードを送信**

   - 公式アカウントに管理者用キーワード（環境変数 `ADMIN_ACCESS_KEYWORD` で設定）を送信
   - 例: `admin2024secret`（実際のキーワードは環境変数で設定）

3. **管理画面 URL を受信**
   - 公式アカウントから管理画面の URL が返信されます
   - 返信された URL をブラウザで開いて管理画面にアクセス

### キーワードの設定方法

#### ローカル開発環境

`.env.local` ファイルに追加：

```env
ADMIN_ACCESS_KEYWORD=your-random-keyword-here
LINE_CHANNEL_ACCESS_TOKEN=your_channel_access_token
LINE_CHANNEL_SECRET=your_channel_secret
NEXT_PUBLIC_ADMIN_URL=http://localhost:3000/admin
```

#### 本番環境（AWS Amplify）

1. AWS Amplify Console にログイン
2. アプリを選択
3. 「Environment variables」を選択
4. 以下の環境変数を追加：
   - **キー**: `ADMIN_ACCESS_KEYWORD`
     - **値**: ランダムな文字列（例: `admin2024secret123`）
     - ⚠️ **重要**: 一般の人が打つことはない、ランダムな文字列を設定してください
   - **キー**: `LINE_CHANNEL_ACCESS_TOKEN`
     - **値**: LINE Messaging API のチャネルアクセストークン
   - **キー**: `LINE_CHANNEL_SECRET`
     - **値**: LINE Messaging API のチャネルシークレット
   - **キー**: `NEXT_PUBLIC_ADMIN_URL`（オプション）
     - **値**: 管理画面のフル URL（例: `https://your-domain.amplifyapp.com/admin`）
     - 設定しない場合、相対パス `/admin` が使用されます
5. 「Save」をクリック
6. 再デプロイを実行

### Webhook URL の設定

LINE Developers Console で Webhook URL を設定する必要があります：

1. [LINE Developers Console](https://developers.line.biz/console/) にアクセス
2. Messaging API チャネルを選択
3. 「Messaging API」タブ → 「Webhook URL」→「編集」
4. Webhook URL を設定：
   - **ローカル開発**: `https://your-ngrok-url.ngrok.io/api/webhook/line`
   - **本番環境**: `https://your-domain.amplifyapp.com/api/webhook/line`
5. 「Webhook の利用」を有効化
6. 「検証」をクリックして接続を確認

### セキュリティ注意事項

- **キーワードの強度**: 推測されにくい、ランダムな文字列を設定してください
- **キーワードの管理**: キーワードは管理者のみが知っている必要があります
- **Webhook 署名検証**: Webhook リクエストの署名は自動的に検証されます

## 🔐 認証情報

### デフォルトパスワード

**パスワード**: `admin`

### パスワードの変更方法

環境変数 `NEXT_PUBLIC_ADMIN_PASSWORD` を設定することで、パスワードを変更できます。

#### ローカル開発環境

`.env.local` ファイルに追加：

```env
NEXT_PUBLIC_ADMIN_PASSWORD=your-secure-password
```

#### 本番環境（AWS Amplify）

1. AWS Amplify Console にログイン
2. アプリを選択
3. 「Environment variables」を選択
4. 以下の環境変数を追加：
   - **キー**: `NEXT_PUBLIC_ADMIN_PASSWORD`
   - **値**: 設定したいパスワード
5. 「Save」をクリック
6. 再デプロイを実行

---

## 📝 ログイン手順

1. **管理画面 URL にアクセス**

   - `/admin` にアクセス

2. **ログイン画面が表示される**

   - パスワード入力フィールドが表示されます

3. **パスワードを入力**

   - デフォルト: `admin`
   - または環境変数で設定したパスワード

4. **「ログイン」ボタンをクリック**

5. **管理画面ダッシュボードが表示される**
   - ログイン成功後、ダッシュボードが表示されます

---

## 🎯 管理画面の機能

ログイン後、以下の機能にアクセスできます：

### 1. ダッシュボード (`/admin`)

- 各管理機能へのクイックアクセス

### 2. ユーザー管理 (`/admin/users`)

- ユーザー一覧の表示
- ユーザー詳細の確認
- ガチャ履歴の確認

### 3. ガチャ設定 (`/admin/gacha-types`)

- ガチャタイプの一覧
- 確率設定（各レアリティの重み）
- 有効/無効の切り替え

### 4. アイテム設定 (`/admin/items`)

- アイテム一覧の表示
- アイテムの追加・編集・削除
- レアリティ別フィルタリング

### 5. 統計・購入状況 (`/admin/statistics`)

- 日別/月別の統計
- ガチャタイプ別実行回数
- レアリティ別獲得数

### 6. ガチャシミュレータ (`/admin/simulator`)

- 指定回数のシミュレーション実行
- 実際の排出率と設定確率の比較

## 🔒 セキュリティ注意事項

### 現在の実装

- **認証方式**: パスワード認証（クライアント側）
- **セッション管理**: `sessionStorage` を使用
- **API 認証**: カスタムヘッダー `X-Admin-Auth` で認証

### ⚠️ 注意点

1. **パスワードの強度**

   - デフォルトパスワード `admin` は本番環境では使用しない
   - 強力なパスワードを設定することを推奨

2. **環境変数の管理**

   - `NEXT_PUBLIC_ADMIN_PASSWORD` はクライアント側に公開される
   - 本番環境では、より強固な認証（JWT、サーバー側セッション管理）を実装することを推奨

3. **アクセス制限**
   - 現在は IP 制限などの追加セキュリティ機能は実装されていない
   - 必要に応じて、IP 制限や 2 要素認証を追加することを検討

---

## 🔄 ログアウト

管理画面のサイドバー下部にある「ログアウト」ボタンをクリックすると、ログアウトできます。

ログアウト後は、再度パスワードを入力してログインする必要があります。

---

## 🛠️ トラブルシューティング

### パスワードが正しくない

- 環境変数 `NEXT_PUBLIC_ADMIN_PASSWORD` が正しく設定されているか確認
- ブラウザのキャッシュをクリア
- セッションストレージをクリア（開発者ツール → Application → Session Storage）

### ログインできない

- ブラウザの JavaScript が有効になっているか確認
- コンソールエラーを確認
- 環境変数が正しく読み込まれているか確認

### API エラーが発生する

- サーバー側の環境変数 `ADMIN_AUTH_TOKEN` が設定されているか確認
- API ルートの認証チェックが正しく動作しているか確認
