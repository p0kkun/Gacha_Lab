# 管理画面 設定項目一覧（お客様向け）

このドキュメントは、**管理画面で「何が設定できるか」**を、知識がない方でも判断できるようにまとめたものです。  
（※画面・API の実装状況に基づくため、将来的に項目が増減する可能性があります）

---

## 0. 影響するフロント画面（ユーザー画面）一覧

管理画面の設定は、主に以下のユーザー画面に影響します。

| 画面名（ユーザー向け） | URL（目安）            | 説明                                                             |
| ---------------------- | ---------------------- | ---------------------------------------------------------------- |
| トップ（ガチャ）       | `/` / `/?action=gacha` | ガチャを回す画面（ポイント消費・確率・動画・当選結果などが反映） |
| マイページ             | `/?action=mypage`      | ユーザー情報/所持ポイント表示など                                |
| ガチャ履歴             | `/?action=history`     | ガチャ実行履歴の閲覧                                             |
| 獲得アイテム           | `/?action=items`       | 獲得したアイテムの表示・使用                                     |
| ヘルプ                 | `/?action=help`        | ヘルプ/説明                                                      |
| 紹介                   | `/?action=referral`    | 紹介リンク関連                                                   |
| ポイント購入           | `/points`              | 購入プランの表示・決済・購入完了（購入プランの変更が反映）       |

※利用規約/プライバシー/特商法（`/terms` `/privacy` `/commercial-transaction`）は、通常は管理画面設定の影響を受けません。

## 1. まず最初に：管理画面でできること（一覧）

管理画面のメニューと、そこでできることの要点です。

| メニュー | できること（要点） | 影響するフロント画面（例） |
| --- | --- | --- |
| ダッシュボード | 各メニューへの入口（概要） | （直接の画面変更なし） |
| ユーザー管理 | ユーザーの検索/確認、ユーザーへのタグ付与/削除 | （直接の画面変更なし） |
| タグ管理 | タグの作成/編集/削除、条件に基づくタグ一括付与 | （直接の画面変更なし） |
| メッセージ配信 | タグ指定 or ユーザー指定でメッセージ一括送信 | LINEメッセージ（アプリ内画面ではなく外部送信） |
| ポイント管理 | 有償/無償ポイントの付与（ユーザー/タグ/全員）＋任意で通知送信 | トップ（ガチャ）/マイページ/ポイント購入（所持ポイント表示） |
| ポイント購入プラン | 購入できる「ポイント数/金額/おまけ無償ポイント/表示順/有効無効」の管理 | ポイント購入（`/points`） |
| ガチャ設定 | ガチャタイプの作成/編集、確率（重み）/役/動画/メッセージテンプレの設定 | トップ（ガチャ）/ガチャ履歴/獲得アイテム |
| 景品割当（ガチャ別） | ガチャタイプごとに「同じ景品を何等扱いにするか」を割り当て（重み付き） | トップ（ガチャ）/ガチャ履歴/獲得アイテム |
| アイテム設定 | ガチャアイテムの作成/編集/無効化、画像アップロード | トップ（ガチャ）/獲得アイテム |
| 動画管理 | 動画アップロード、（有効/無効）、デフォルト動画設定 | トップ（ガチャ） |
| 統計・購入状況 | 期間やガチャで絞り込んだ集計の閲覧 | （直接の画面変更なし） |
| ガチャシミュレータ | 設定した確率でのシミュレーション実行（回数指定） | （直接の画面変更なし） |
| 操作履歴 | 管理画面操作ログの閲覧・絞り込み | （直接の画面変更なし） |

## 2. 共通：管理画面の使い方と注意

- **権限/認証**: 管理画面はパスワードでログインします。
  - 設定: **`NEXT_PUBLIC_ADMIN_PASSWORD`**（環境変数）
  - 補足: **今後は「登録制（管理者アカウント管理）」へ変更予定**です（現状は暫定仕様）。
- **反映タイミング**:
  - 多くの設定は「保存」ボタン押下後、即時反映されます。
- **注意（重要）**:
  - 変更はユーザー体験に直結します（確率、消費ポイント、動画、購入プランなど）。  
    変更前に影響範囲を確認してください。

## 3. 各メニューの詳細（設定項目）

### 3.1 ユーザー管理（`/admin/users`）

#### 3.1.1 目的

ユーザーを探して詳細を確認し、必要に応じて**タグを付与/削除**します。

#### 3.1.2 できること

- **検索**: ユーザー ID / 表示名で検索
- **並び替え**: 登録日時 / 表示名 / ガチャ実行回数
- **ユーザー詳細の閲覧**（編集ではなく閲覧）
  - 基本情報、直近ガチャ履歴、各種カウント、レアリティ別集計
- **ユーザーへのタグ付与**
- **ユーザーからタグ削除**

#### 3.1.3 反映

タグ付与/削除は即時反映されます。

---

### 3.2 タグ管理（`/admin/tags`）

#### 3.2.1 目的

ユーザーを分類するための「タグ」を作成し、運用で使います。

#### 3.2.2 設定できる項目

- **タグ作成**
  - タグ名（必須）
  - 説明（任意）
- **タグ編集**
  - タグ名
  - 説明
- **タグ削除**
  - ただし、**ユーザーに付与済み（使用中）のタグは削除できません**（先にユーザーから外してください）

---

### 3.3 タグ一括付与（`/admin/tags/bulk-assign`）

#### 3.3.1 目的

条件に合うユーザーに対して、指定タグをまとめて付与します。

#### 3.3.2 設定できる項目（条件）

以下の条件を組み合わせて、対象ユーザーを絞り込みます（基本は **AND 条件**）。

- **特定ガチャタイプを引いたユーザー**（ガチャタイプ ID）
- **最小課金額**（一定以上購入した人）
- **最小紹介人数**（紹介成立人数）
- **特定レアリティ当選**
- **アイテム使用済み/未使用**
- **最小ガチャ実行回数**

#### 3.3.3 操作の流れ（おすすめ）

- 条件を設定 → 対象人数をプレビュー → 問題なければ実行

---

### 3.4 メッセージ配信（`/admin/messages`）

#### 3.4.1 目的

ユーザーへ一括メッセージを送信します（LINE のメッセージ送信を想定）。

#### 3.4.2 設定できる項目

- **メッセージ本文**
- **送信対象の選び方**
  - タグで選択（複数可）
  - ユーザーで選択（複数可）

#### 3.4.3 注意

- 一括送信は対象人数が多いほど時間がかかります。
- 送信先のユーザー状態（ブロック等）により失敗が出る場合があります。

---

### 3.5 ポイント管理（付与）（`/admin/points`）

#### 3.5.1 目的

有償/無償ポイントをユーザーへ付与します（キャンペーン、補填など）。

#### 3.5.2 設定できる項目

- **付与対象**
  - 特定ユーザー（検索して選択）
  - タグで選択（複数タグ可）
  - 全ユーザー
- **ポイント種別**
  - 有償（PAID）
  - 無償（FREE）
- **付与ポイント数**
- **説明（任意）**
- **通知送信（任意）**
  - 通知送信の ON/OFF
  - 通知メッセージ（任意、未入力ならデフォルト文）

#### 3.5.3 反映

付与は即時反映されます（履歴も記録されます）。

---

### 3.6 ポイント購入プラン（`/admin/point-plans`）

#### 3.6.1 目的

ユーザーが購入できる「ポイント数/金額」を管理します。

#### 3.6.2 設定できる項目

- **新規作成**
  - プラン ID（必須、英数字/ハイフン/アンダースコア）
  - ラベル（例: 100 ポイント）
  - 付与ポイント数（有償）
  - おまけ無償ポイント（購入特典、0 以上）
  - 価格（円）
  - 表示順（小さいほど先に表示）
  - 有効/無効
- **既存プランの更新**
  - ラベル
  - 付与ポイント数（有償）
  - おまけ無償ポイント（購入特典）
  - 価格（円）
  - 表示順
  - 有効/無効
- **削除**
  - 不要になった購入プランの削除（取り消し不可）

#### 3.6.3 反映

- 購入画面（`/points`）は、**有効なプランのみ**表示します。
- 購入が完了すると、**「有償ポイント」＋「おまけ無償ポイント」**が付与されます（プラン設定に従います）。

#### 3.6.4 注意（重要）

- プラン ID は決済処理の識別にも使用されるため、**作成後に変更しない運用**を推奨します。  
  （現状の実装でも、ID の変更はできない想定です）
- 価格や付与ポイント数を変更すると、購入画面の内容も即時変わります。運用上は「新しいプランを作る」方が安全なケースがあります。

---

### 3.7 ガチャ設定（`/admin/gacha-types`）

#### 3.7.1 目的

ガチャタイプ（例: 通常/プレミアム等）の設定を行います。

#### 3.7.2 設定できる項目（代表例）

- **基本情報**
  - ID / 名前 / 説明
  - アイコン画像（アップロード）
  - 有効/無効
  - 開始日時 / 終了日時（時間まで指定可能）
  - 1 回あたりの消費ポイント（`pointCost`）
- **確率（重み）設定**
  - 等級ごとの重み（確率に相当）
  - 表示順（等級の並び）
- **役（ポーカー hand）設定**
  - 等級ごとに対応する役（複数設定可）
- **動画設定**
  - デフォルト動画を使用するか（`useDefaultVideos`）
  - 共通動画（前半）候補 ID 配列
  - 等級別動画（後半）候補 ID 設定
- **結果メッセージテンプレート**
  - 送信メッセージの雛形（差し込み変数あり）

#### 3.7.3 注意

- 確率/消費ポイントの変更はユーザー体験・売上に直結します。

---

### 3.8 アイテム設定（`/admin/items` / `/admin/items/[id]`）

#### 3.8.1 目的

ガチャで獲得できるアイテムの内容を管理します。

#### 3.8.2 設定できる項目

- 名前
- レアリティ（※等級は「景品割当（ガチャ別）」で管理）
- 使用方法（画像表示 / 店員に見せる）
- 使用画像（画像アップロード対応、`imageUrl`）
- 使用開始日時（任意、時間まで指定可能）
- 使用期限（任意、時間まで指定可能）
- 有効/無効（無効化は論理削除）

---

### 3.8.5 景品割当（ガチャ別）（`/admin/prize-assignments`）

#### 3.8.5.1 目的

同じ景品（例: カードスリーブ）でも、**ガチャタイプごとに「何等扱い」にするかを変えられる**ようにします。  
例: 1000円ガチャでは3等、3000円ガチャでは5等 など。

#### 3.8.5.2 設定できる項目

- ガチャタイプ（対象のガチャを選択）
- 等級（1等〜5等/ハズレ）
- 景品（アイテム）
- 重み（同じ等級内で複数景品がある場合の当たりやすさ）
- 有効/無効

#### 3.8.5.3 反映

- ガチャ実行時の景品抽選に即時反映されます。
- ガチャ履歴/獲得アイテムの「等級表示」は、この割当（ガチャ別の等級）に基づきます。

---

### 3.9 動画管理（`/admin/videos`）

#### 3.9.1 目的

ガチャ演出に使用する動画をアップロード/管理します。

#### 3.9.2 設定できる項目

- **動画アップロード**
  - 動画タイプ（共通/等級別）
  - 説明（任意）
- **動画の更新（現在の画面でできること）**
  - 有効/無効
- **動画削除**
  - 削除前に「どこで使われているか」を確認してから削除
- **デフォルト動画設定（全体）**
  - 共通動画 ID 配列
  - 等級別動画 ID 設定

---

### 3.10 統計・購入状況（`/admin/statistics`）

#### 3.10.1 目的

運用の判断材料として、集計結果を確認します。

#### 3.10.2 設定できる項目（集計条件）

- 期間: 今日 / 今月 / 期間指定（開始日・終了日）
- ガチャ絞り込み:
  - すべて
  - 現行稼働のみ
  - 過去のみ
  - 選択したガチャのみ（複数選択）

---

### 3.11 ガチャシミュレータ（`/admin/simulator`）

#### 3.11.1 目的

設定した確率（重み）で、理論値と実際のばらつきを確認します。

#### 3.11.2 設定できる項目（実行パラメータ）

- 対象ガチャタイプ
- 実行回数（100〜1,000,000）

---

### 3.12 操作履歴（`/admin/action-history`）

#### 3.12.1 目的

管理画面で誰が何をしたかを追跡します（監査）。

#### 3.12.2 絞り込み条件

- 操作タイプ
- 管理者ユーザー ID
- 対象ユーザー ID
- 開始日 / 終了日

---
