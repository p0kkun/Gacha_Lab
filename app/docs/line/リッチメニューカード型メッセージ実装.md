# リッチメニューカード型メッセージ実装

## 概要

リッチメニューのガチャボタンを押すと、トークでカードタイプメッセージ（カルーセル）が表示され、そのカードを選択するとガチャ画面（LIFF アプリ）に遷移する機能を実装しました。

## 実装内容

### 1. フロー

```
1. ユーザーがリッチメニューの「ガチャ」ボタンを押す
   ↓
2. ポストバックイベントがWebhookに送信される
   ↓
3. ガチャタイプ一覧を取得
   ↓
4. カードタイプメッセージ（カルーセル）を送信
   ↓
5. ユーザーがカードを選択
   ↓
6. LIFFアプリが開き、選択したガチャタイプの画面が表示される
```

### 2. 実装ファイル

- **`app/api/webhook/line/route.ts`**: ポストバックイベント処理とカードメッセージ送信

### 3. 主な機能

#### ポストバックイベントの処理

リッチメニューのボタンが押されると、ポストバックイベントが送信されます。

```typescript
if (event.type === "postback") {
  const postbackEvent = event as PostbackEvent;
  const data = postbackEvent.postback.data;

  // ガチャボタンが押された場合
  if (data === "action=gacha" || data.startsWith("gacha")) {
    await sendGachaSelectionCard(client, postbackEvent.replyToken);
  }
}
```

#### ガチャタイプ一覧の取得

有効で期間内のガチャタイプを取得します。

```typescript
const gachaTypes = await prisma.gachaType.findMany({
  where: {
    isActive: true,
    // 期間チェック
  },
  take: 10, // カルーセルは最大10個まで
});
```

#### カードタイプメッセージ（カルーセル）の送信

各ガチャタイプをカードとして表示します。

```typescript
const columns: CarouselColumn[] = gachaTypes.map((gachaType) => ({
  thumbnailImageUrl: "画像URL",
  title: gachaType.name,
  text: `${gachaType.description}\n💰 ${pointCostText}`,
  actions: [
    {
      type: "uri",
      label: "このガチャを引く",
      uri: getLiffUrl({
        action: "gacha",
        gachaTypeId: gachaType.id,
      }),
    },
  ],
}));
```

## リッチメニューの設定手順

### 1. LINE Official Account Manager で設定

1. **LINE Official Account Manager**にログイン
2. 作成した公式アカウントを選択
3. 「リッチメニュー」→「新規作成」または既存のリッチメニューを編集

### 2. ガチャボタンのアクション設定

#### 方法 1: メッセージアクション（推奨・簡単）

LINE Official Account Manager の UI で直接設定できる方法です。

**ボタン設定（例：左上のガチャボタン）:**

- **エリア**: 左上（x: 0, y: 0, width: 1250, height: 843）
- **アクションタイプ**: **メッセージアクション**
- **ラベル**: ガチャ
- **送信メッセージ**: `ガチャ` または `gacha` または `🎰`

**設定手順:**

1. LINE Official Account Manager でリッチメニューを編集
2. ガチャボタンのエリアを選択
3. 「アクション」を選択
4. 「メッセージアクション」を選択
5. 「送信メッセージ」に `ガチャ` と入力
6. 「ラベル」に `ガチャ` と入力
7. 保存

**動作:**

- ユーザーがボタンを押すと、トークに「ガチャ」というメッセージが送信されます
- Webhook でこのメッセージを受信し、カードタイプメッセージを返信します

**対応キーワード:**

- `ガチャ`
- `gacha`
- `🎰`
- `ガチャを引く`
- `ガチャを選ぶ`

これらのキーワードのいずれかが含まれていれば、カードメッセージが送信されます。

#### 方法 2: ポストバックアクション（API 経由で設定する場合）

LINE Official Account Manager の UI ではポストバックアクションが選択できない場合があります。その場合は、Messaging API を使用してリッチメニューを設定する必要があります。

**ボタン設定（例：左上のガチャボタン）:**

- **エリア**: 左上（x: 0, y: 0, width: 1250, height: 843）
- **アクションタイプ**: **ポストバックアクション**
- **ラベル**: ガチャ
- **データ**: `action=gacha`

**設定例（JSON）:**

```json
{
  "type": "postback",
  "label": "ガチャ",
  "data": "action=gacha",
  "displayText": "ガチャを選択"
}
```

**重要**:

- `type`は`postback`を指定
- `data`は`action=gacha`を指定（Webhook でこの値を受け取ります）
- `displayText`は任意（トーク画面に表示されるテキスト）

**注意**: ポストバックアクションは、LINE Official Account Manager の UI では直接設定できない場合があります。その場合は、Messaging API を使用してリッチメニューを設定する必要があります。

### 3. その他のボタン（従来通り）

他のボタン（マイページ、履歴など）は従来通り**URI アクション**のまま設定してください。

**例：マイページボタン**

- **アクションタイプ**: URI アクション
- **URI**: `https://liff.line.me/2008642684-d8jPmggE?action=mypage`

## LIFF アプリ側の実装

### URL パラメータの処理

LIFF アプリ側で、URL パラメータからガチャタイプ ID を取得して処理します。

**例：`app/page.tsx`または該当ページ**

```typescript
useEffect(() => {
  const urlParams = new URLSearchParams(window.location.search);
  const action = urlParams.get("action");
  const gachaTypeId = urlParams.get("gachaTypeId");

  if (action === "gacha" && gachaTypeId) {
    // 指定されたガチャタイプの画面を表示
    setSelectedGachaTypeId(gachaTypeId);
  }
}, []);
```

## カスタマイズ

### カード画像の設定

現在はプレースホルダー画像を使用しています。実際の画像 URL に変更してください。

**`app/api/webhook/line/route.ts`の`sendGachaSelectionCard`関数内:**

```typescript
thumbnailImageUrl: 'https://via.placeholder.com/1024x1024/FF6B6B/FFFFFF?text=GACHA',
```

**推奨:**

- 各ガチャタイプに専用の画像を設定
- 画像サイズ: 1024×1024px（推奨）
- 形式: JPEG または PNG

**例：**

```typescript
// ガチャタイプごとに画像URLを設定
const getGachaImageUrl = (gachaTypeId: string) => {
  return `https://your-domain.com/images/gacha/${gachaTypeId}.jpg`;
};

thumbnailImageUrl: getGachaImageUrl(gachaType.id),
```

### カードの表示内容

カードのタイトル、テキスト、アクションボタンのラベルをカスタマイズできます。

**現在の設定:**

- **タイトル**: ガチャタイプ名
- **テキスト**: 説明文 + ポイントコスト
- **アクションボタン**: 「このガチャを引く」

**カスタマイズ例:**

```typescript
{
  title: `🎰 ${gachaType.name}`,
  text: `${gachaType.description || ''}\n💰 ${pointCostText}\n🎁 豪華な景品が当たる！`,
  actions: [
    {
      type: 'uri',
      label: '🎯 今すぐ引く',
      uri: getLiffUrl(`gacha&gachaTypeId=${gachaType.id}`),
    },
  ],
}
```

## 動作確認

### 1. ローカル環境での確認

1. **Webhook URL を設定**

   - LINE Developers Console で Webhook URL を設定
   - ローカル環境では ngrok などでトンネリングが必要

2. **リッチメニューを設定**

   - LINE Official Account Manager でリッチメニューを作成
   - ガチャボタンにポストバックアクションを設定

3. **動作確認**
   - リッチメニューのガチャボタンを押す
   - トークでカードタイプメッセージが表示されることを確認
   - カードを選択して LIFF アプリが開くことを確認

### 2. 本番環境での確認

1. **環境変数の確認**

   - `NEXT_PUBLIC_LIFF_ID`: LIFF アプリ ID
   - `LINE_CHANNEL_ACCESS_TOKEN`: LINE Messaging API のアクセストークン
   - `LINE_CHANNEL_SECRET`: LINE Messaging API のチャンネルシークレット
   - `DATABASE_URL`: データベース接続 URL

2. **リッチメニューの公開**
   - リッチメニューを「公開」に設定
   - 友だち追加したユーザーに表示されることを確認

## トラブルシューティング

### カードメッセージが表示されない

**原因:**

- ポストバックイベントが正しく処理されていない
- ガチャタイプが取得できていない

**確認事項:**

1. Webhook のログを確認（`console.log`で出力）
2. データベースに有効なガチャタイプが存在するか確認
3. リッチメニューの`data`プロパティが正しく設定されているか確認

### LIFF アプリが開かない

**原因:**

- URL パラメータが正しく設定されていない
- LIFF ID が間違っている

**確認事項:**

1. `getLiffUrl`関数で生成される URL を確認
2. LIFF アプリ側で URL パラメータを正しく処理しているか確認

### 画像が表示されない

**原因:**

- 画像 URL が無効
- 画像サイズが大きすぎる

**確認事項:**

1. 画像 URL が正しく設定されているか確認
2. 画像サイズを 1024×1024px 以下に調整
3. HTTPS で配信されているか確認
