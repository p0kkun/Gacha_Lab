# リッチメニューから紹介機能への遷移設定

## 概要

リッチメニューの「友だち紹介」ボタンから紹介機能（`action=referral`）に遷移できるように設定します。

---

## 📋 設定手順

### 1. LINE Official Account Manager での設定

1. **LINE Official Account Manager にログイン**

   - https://manager.line.biz/ にアクセス

2. **リッチメニューの編集**

   - 対象の公式アカウントを選択
   - 「リッチメニュー」→ 既存のリッチメニューを編集、または新規作成

3. **「友だち紹介」ボタンの設定**

#### 開発環境用

- **エリア**: 右下（x: 1250, y: 843, width: 1250, height: 843）
- **アクションタイプ**: URI アクション
- **URI**: `https://miniapp.line.me/2008642684-d8jPmggE?action=referral`
- **ラベル**: 友だち紹介

#### 審査環境用

- **エリア**: 右下（x: 1250, y: 843, width: 1250, height: 843）
- **アクションタイプ**: URI アクション
- **URI**: `https://miniapp.line.me/2008642685-xyZrjKKN?action=referral`
- **ラベル**: 友だち紹介

#### 本番環境用

- **エリア**: 右下（x: 1250, y: 843, width: 1250, height: 843）
- **アクションタイプ**: URI アクション
- **URI**: `https://miniapp.line.me/2008642686-qmd6bXXk?action=referral`
- **ラベル**: 友だち紹介

## ✅ 動作確認

### 1. アプリ側の実装確認

`app/page.tsx`で`action=referral`の処理が実装されていることを確認：

```typescript
} else if (action === "referral") {
  setActivePage("referral");
}
```

### 2. リッチメニューからの遷移確認

1. LINE 公式アカウントを友だち追加
2. リッチメニューの「友だち紹介」ボタンをタップ
3. LIFF アプリが開き、紹介機能ページが表示されることを確認

### 3. 紹介機能の動作確認

- 紹介リンクの生成ができること
- QR コードが表示されること
- 紹介履歴が表示されること

## 🔧 トラブルシューティング

### 問題: リッチメニューから遷移しても紹介ページが表示されない

**確認事項:**

1. `app/page.tsx`で`action=referral`の処理が実装されているか
2. `Referral`コンポーネントが正しくインポートされているか
3. 環境変数`NEXT_PUBLIC_LIFF_URL`が正しく設定されているか

### 問題: リッチメニューのボタンを押してもアプリが開かない

**確認事項:**

1. LINE Developers Console で LIFF アプリのエンドポイント URL が正しく設定されているか
2. リッチメニューの URI が正しい LIFF URL になっているか
3. リッチメニューが「公開」状態になっているか
